Version 6.0
-----------

Version 6.0 drops support for Python versions 3.8 and Python 3.9 and removes code that became deprecated in version 5.2.

Breaking changes
~~~~~~~~~~~~~~~~

- Python >= 3.10 is now required.

Features
~~~~~~~~

- Support for Sphinx 9.

Maintenance
~~~~~~~~~~~

- Updated developer tooling
- Replaced Alpine.js with vanilla JavaScript.
  If you override ``header.html``, ``sidebar.html``, ``scrolltop.html`` or ``layout.html`` with a copy of the old markup,
  replace the Alpine attributes with the new ``data-*`` hooks:
  ``data-theme-toggle`` (color scheme button),
  ``data-sidebar-open`` and ``data-sidebar-close`` (mobile sidebar buttons).
